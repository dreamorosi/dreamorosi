## Hello &bull; Ciao &bull; Hola 👋

I'm Andrea, a software engineer at AWS. I'm a Senior AI Engineer and the tech lead for AI Engineering EMEA, so most of my week goes to helping software companies get AI agents doing real work in production, beyond helping engineers write code. I also work on [AI-DLC](https://github.com/awslabs/aidlc-workflows), AWS's open-source framework for AI-driven development, where I bring what large companies adopting it need back into the roadmap.

Before that I spent four years on [Powertools for AWS Lambda](https://github.com/aws-powertools). I was a founding maintainer of the [TypeScript version](https://github.com/aws-powertools/powertools-lambda-typescript) and later the tech lead across Python, TypeScript, Java and .NET. I merged close to 700 pull requests along the way, most of them written by hand, before LLMs started doing the typing.

The repos on this profile are mostly small tools I build for myself, in TypeScript and lately Rust. Things like a [CLI to scaffold CDK apps](https://github.com/dreamorosi/create-cdk-app-cli), a [reminders CLI for CalDAV](https://github.com/dreamorosi/caldav-reminders-cli) and a [doc viewer for OpenCode](https://github.com/dreamorosi/opencode-docview).

I write about what I'm building at [andrebuilds.dev](https://andrebuilds.dev). Italian 🇮🇹, in Barcelona 🇪🇸 since 2017.
